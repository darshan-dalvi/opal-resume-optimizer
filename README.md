# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/1eed28e2-35f3-4f0b-b432-618378e06961

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
3. In the upload screen, choose an AI provider, select or enter a model, and paste the matching API key.

Notes:
- The app no longer assumes Gemini by default.
- API keys are entered in the frontend and stay in the current browser session.
